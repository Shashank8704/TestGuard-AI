**Bob action:** Asked Bob to act as lead software architect for an 8-hour hackathon project.

**Output produced:**
- Complete project plan document (`testguard-ai-plan.md`)

### Phase 3 — Code Generation with Bob

**Bob action:** Bob implemented the full Python AST analysis engine.

**Files generated by Bob:**
- `backend/analyzer/ast_analyzer.py`
  - `parse_functions()` — extracts function definitions, arguments, branch counts
  - `parse_branches()` — walks if/elif/else trees, extracts conditions and line numbers
  - `detect_boundary_conditions()` — identifies numeric comparisons and suggests test values
  - `detect_missing_tests()` — cross-references branches against covered functions
  - `detect_edge_cases()` — infers edge cases from argument name heuristics
  - `analyze_code()` — master function combining all analysis

**Bob validation:** Bob ran the discount example through the analyzer inline during development to verify it found at least 1 branch and 2 missing tests before proceeding.

### Phase 5 — AI Integration with Bob

**Bob action:** Bob designed and implemented the Google Gemini integration with graceful degradation.

**File generated by Bob:**
- `backend/analyzer/ai_layer.py`
  - Structured prompt engineering: sends code, tests, and AST findings to Gemini
  - JSON-mode response parsing via `response_mime_type: application/json`
  - Full try/except fallback: any API failure returns `ai_available: False`
  - Cautious language enforcement in prompt: "Potential missing tests", never "guaranteed"

**Bob design decision:** The prompt explicitly instructs Gemini to not repeat AST-detected scenarios — only add novel AI insights. This prevents duplicate results in the merged response.

**Bob integration work:** Bob diagnosed the OpenAI → Gemini migration, identified the correct `google-genai` SDK (v2+), resolved model availability issues (selecting `gemini-flash-lite-latest` as the stable available model), and updated all environment variable names from `OPENAI_API_KEY` to `GEMINI_API_KEY`.

## Key Technical Decisions Made with Bob

| Decision | Rationale |
|----------|-----------|
| AST-first, AI-enhanced | App always works without Gemini key |
| `ai_available: bool` in response | Frontend can show "Static Analysis Only" gracefully |
| Vite proxy to FastAPI | Eliminates CORS issues in development |
| React Router `location.state` | No Redux, no global store — simpler and faster |
| Google Gemini (`gemini-flash-lite-latest`) | Free API key via AI Studio, no billing required |
| `response_mime_type: application/json` | Structured AI output, no parsing fragility |
| Template fallback generator | Demo always works even if AI is unavailable |
